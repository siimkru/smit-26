# Security policy

## Supported versions

This repository is a small assignment project. Only the latest revision on the
`main` branch is supported.

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue. Contact the
repository owner privately through GitHub so the issue can be investigated and
fixed before public disclosure.

Include the affected file or workflow, a short description of the impact, and
reproduction steps that do not contain real credentials or other sensitive data.

This project does not accept secrets, personal data, or production credentials
in issues, pull requests, or test fixtures.
